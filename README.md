# Ruta Real

Web pública de Ruta Real: rutas accesibles por Sevilla para personas con movilidad reducida, con Rachel, nuestra asistente de IA.

- **Quiénes somos**: qué problema resolvemos y qué queremos aportar.
- **Mapa interactivo** de Sevilla: búsqueda de cualquier lugar, rutas según el perfil de movilidad, metro y tranvía, aseos adaptados, lugares accesibles y avisos de obstáculos.
- **Premium** (4,99 €/mes) y enlace a Instagram [@somosrutareal](https://www.instagram.com/somosrutareal).
- **Quejas y sugerencias**.
- **Rachel**, en el lateral, para preguntar cualquier cosa.

Es una web estática (HTML, CSS y JS) publicada con GitHub Pages. La configuración (enlace de pago, destino de las quejas, servidor de IA) está en `config.js`.

Datos del mapa: © colaboradores de OpenStreetMap. Rutas: Valhalla (FOSSGIS). Búsqueda: Nominatim.
